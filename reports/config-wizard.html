1. Enforcement & Failure Gate

Select the minimum severity threshold required to block Git commits, PR merges, or CI/CD pipelines.

High & Critical

Recommended for production. Blocks code injection, broken crypto, leaked credentials, and authorization flaws.

Critical Only

Permissive stance. Only blocks severe immediate risks like plaintext API keys and remote code execution.

Medium & Above

Strict security posture. Blocks weak password hashing, missing cookie flags, and unhandled debug leaks.

All Findings (Low+)

Zero-tolerance hygiene. Flags all minor security smells, documentation gaps, and informational warnings.
