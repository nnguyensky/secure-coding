# Password Storage patterns (OWASP Password Storage CS)
# New ID distinct from existing: pw-slow-hash
# Note: existing pw-fast-hash catches fast hashes ON passwords.
#       pw-slow-hash catches plaintext/weak storage patterns.
# Section 20 in the skill's group numbering.
#
# id	exts	regex	!exclude	hint

pw-slow-hash	*	const\s+(password|passwd|pwd)\s*[:=]\s*["'][^"']+["']\s*;	hardcoded password in source — move to env or secret manager		critical
